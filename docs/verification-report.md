## 알려진 데이터 한계

1. 공개 기본 피해는 소수점 한 자리 표시값. 내부 raw telemetry와 PUBG 반올림 규칙은 미확인이다.
2. 표본 사이 선형 보간은 자체 근사 모델이다. 측정 구간 밖은 null.
3. 공개 RPM, Normal 다중 발 TTK, 조준경별 2발 TTK에서 유도한 간격은 derived 값이다. 원시 엔진 timing으로 주장하지 않는다.
4. S686/Sawed-off/DBS의 2발 이후 재장전·추가 작동 시간은 미확인이라 TTK null. 일반 cadence 모델은 재장전을 제외한다.
5. RPD 외 총구 속도와 Lynx 탄약 등 확보하지 않은 정보는 null. 모든 무기의 모든 변경 기록을 독립 검증했다는 주장은 하지 않는다.

`reference-analysis.md`, `data-model.md`, `damage-engine.md`, `data-sources.md`에 출처와 적용 규칙을 명시했다. 배포 후 검증은 별도 기록으로 추가한다.
